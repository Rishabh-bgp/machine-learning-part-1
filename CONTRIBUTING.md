# Contributing

These are personal practice notebooks, but suggestions are welcome.

1. Fork and create a branch.
2. `pip install -r requirements.txt && python scripts/download_data.py`
3. Make your change and re-execute the affected notebook so outputs stay in sync.
4. Open a pull request describing the change.

Please don't commit datasets without a licence that allows redistribution, virtual environments or `.ipynb_checkpoints`.
Contributions are released under the MIT licence.
